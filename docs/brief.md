# Explore Jerusalem – תקציר פרויקט

פרויקט סטטי מלא ברמת Front-End בהתאם לדרישות הקורס (יחידות 13–20):

- 7 עמודים: בית, חוויות, אוכל, חיי לילה, אירועים, אודות, צור קשר
- ניווט פנימי מלא + לינקים חיצוניים
- פריסה רספונסיבית: CSS Grid + Flexbox + Media Queries (3 גדלים)
- קובץ CSS חיצוני אחד לעיצוב, טיפוגרפיה, צבעים, ריווחים ואפקטי hover
- שימוש ב-HTML סמנטי: header, nav, main, section, article, aside, footer
- טופס יצירת קשר בעמוד "צור קשר"
- תקינה ל-RTL ושפה עברית
- תיקיות: /html, /css, /media, /docs

הערות מדיה:
- הקובץ media/hero-jerusalem.svg הוא פלייסהולדר. מומלץ להחליף לתמונה אמיתית של ירושלים עם זכויות שימוש מתאימות, באותו שם קובץ לשמירה על התאמה.
- סמל האתר media/logo.svg הוא לוגו וקטורי פשוט.

רשימת מקורות חיצוניים מומלצים (לינקים קיימים באתר):
- ויקיפדיה – ירושלים
- iTravelJerusalem – האתר הרשמי לתיירות בירושלים
- Google Maps – מפות ירושלים

מבנה רספונסיבי:
- מובייל: < 768px
- טאבלט: 768–1023px
- דסקטופ: ≥ 1024px
